Single release-level proof artifact for the complete Leonix Quick program. It supersedes the
fragmented per-stack certifications **for PM release purposes only** — it does not retract them.
Classifieds (`7555fb64`), Business Core (`b66322ba`) and Remaining Families (`fe248f22`) remain
certified in their own artifacts and are re-proved here against current source.

- Base: `origin/main` `fd9094994aa2a63fdcea49f24b2435300a7b49a4`, behind 0. The application
  code SHA above is 17 commits ahead of base; every commit after it changes only `docs/` and
  `scripts/`, so `app/` is byte-identical to that SHA.
- Machine checker: `scripts/verify-quick-final-all-program-proof-01.ts`

Every row is validated mechanically: unique ids, allowed statuses, all 19 families present, all
five entry strategies represented, non-empty evidence on every `PROVEN` row, a declared
`BLOCKER_CLASS=` and `REQUIRED=` on every `BLOCKED` row, and existence on disk of every
backticked repository path cited in any cell.

Allowed status values: `PROVEN`, `PROVEN_NA`, `BLOCKED`, `REPAIR_REQUIRED`.

Entry strategies: `QUICK_FORM`, `EXISTING_SHORT_FORM`, `DIRECT_CANONICAL_LINK`,
`DISCOVERY_DESTINATION`, `CONTENT_DESTINATION` (plus `CROSS_CUTTING` for system rows).
